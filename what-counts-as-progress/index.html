02

One history. Two point rules.

Answer a question, repeat it, try a new one, or read an explanation. Both counters use exactly the same actions. Only the point rule changes.

Mini lesson: compare rates when the group sizes differ

A count tells you how many events happened. A rate relates that count to the relevant number of opportunities or people.

Rate = event count ÷ relevant denominator

For example, 12 events among 200 opportunities is 6%; 9 among 100 is 9%. The first group has more events but a lower rate. Check that the event definitions and periods are comparable. Without a suitable denominator, counts alone cannot establish which group has the higher rate.

These are fictional teaching numbers, not real risk estimates.

03

Apply the idea outside the points.

Try an unfamiliar example. This is an unscored teaching check: it changes neither practice counter and is not a validated transfer test.

A fictional reading service adds subscribers. In June, 18 of 300 subscribers cancel; in July, 24 of 600 cancel. A manager says, “The cancellation rate got worse because cancellations rose.” Which response is best supported?

In a future study, learning would need a separate, prespecified assessment with unfamiliar items. The two rules would need to be compared with participants under a reviewed study protocol. This page is a demonstration of the design contrast.
